# Single-cell RNA-seq data description

The `scdata` directory contains processed single-cell RNA-seq expression
profiles used as the target domain for M4DR transfer learning.

Due to the large size of single-cell expression matrices, these files are
not included in the public GitHub repository.

Users should download the corresponding raw single-cell sequencing datasets
from the Gene Expression Omnibus (GEO) database and reproduce the
preprocessing workflow described in this repository.
